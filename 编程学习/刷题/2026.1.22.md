## 530.二叉搜索树的最小绝对差
### 定义位置：
1. 函数内部：函数结束调用，一次递归结束生命周期就结束了
2. 函数外部：private下面也就是，全局的，类还在，变量就还在。

### demo递归法
```cpp
class Solution {
private:
int result = INT_MAX;
TreeNode* pre = NULL;
void traversal(TreeNode* cur) {
    if (cur == NULL) return;
    traversal(cur->left);   // 左
    if (pre != NULL){       // 中
        result = min(result, cur->val - pre->val);
    }
    pre = cur; // 记录前一个
    traversal(cur->right);  // 右
}
public:
    int getMinimumDifference(TreeNode* root) {
        traversal(root);
        return result;
    }
};
```

## 501.二叉搜索树中的众数

### demo
```cpp
class Solution {
private:
    int maxCount = 0; // 最大频率
    int count = 0; // 统计频率
    TreeNode* pre = NULL;
    vector<int> result;
    void searchBST(TreeNode* cur) {
        if (cur == NULL) return ;

        searchBST(cur->left);       // 左
                                    // 中
        if (pre == NULL) { // 第一个节点
            count = 1;
        } else if (pre->val == cur->val) { // 与前一个节点数值相同
            count++;
        } else { // 与前一个节点数值不同
            count = 1;
        }
        pre = cur; // 更新上一个节点

        if (count == maxCount) { // 如果和最大值相同，放进result中
            result.push_back(cur->val);
        }

        if (count > maxCount) { // 如果计数大于最大值频率
            maxCount = count;   // 更新最大频率
            result.clear();     // 很关键的一步，不要忘记清空result，之前result里的元素都失效了
            result.push_back(cur->val);
        }

        searchBST(cur->right);      // 右
        return ;
    }

public:
    vector<int> findMode(TreeNode* root) {
        count = 0;
        maxCount = 0;
        pre = NULL; // 记录前一个节点
        result.clear();
        searchBST(root);
        return result;
    }
};
```

count相等 与 更新最大 maxcount

## 236.二叉树的最近公共祖先
后序遍历；

### demo
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == q || root == p || root == NULL) return root;
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        if (left != NULL && right != NULL) return root;

        if (left == NULL && right != NULL) return right;
        else if (left != NULL && right == NULL) return left;
        else  { //  (left == NULL && right == NULL)
            return NULL;
        }

    }
};
```
### 第一阶段：下潜 (Diving) —— 寻找目标

程序从根节点 `3` 开始，一路向左下潜，直到撞到南墙。

1. **Node 3**: `lowestCommonAncestor(3, ...)`
    
    - 不是 p，不是 q，不是 NULL。
        
    - **动作**：呼叫左下属 `root->left` (Node 5)。
        
2. **Node 5**: `lowestCommonAncestor(5, ...)`
    
    - 不是 p，不是 q。
        
    - **动作**：呼叫左下属 `root->left` (Node 6)。
        
3. **Node 6**: `lowestCommonAncestor(6, ...)`
    
    - **判定**：`root == p` (我是 6！)。
        
    - **动作**：**直接返回 `6`**。
        
    - _潜台词：“老大，我找到 p 了！就在我这！”_
        
    - _(注意：6 的子树根本不会被遍历，递归在这里触底反弹)_
        

---

### 第二阶段：回溯与搜寻 (Backtracking & Searching) —— 左右互搏

现在控制权回到了 **Node 5** 手里。

**Node 5 的视角：**

- `TreeNode* left` 接收到了 **6**（从刚才的左边传回来的）。
    
- **动作**：那再去右边找找 q 吧。呼叫 `root->right` (Node 2)。
    

4. **Node 2**: `lowestCommonAncestor(2, ...)`
    
    - 不是 p，不是 q。
        
    - **动作**：先呼叫左边 (Node 7)。
        
5. **Node 7**: `lowestCommonAncestor(7, ...)`
    
    - 它是叶子，且不是目标。
        
    - **动作**：返回 `NULL`。
        
6. **Node 2 (再次视角)**:
    
    - `left` 接收到了 `NULL`。
        
    - **动作**：呼叫右边 (Node 4)。
        
7. **Node 4**: `lowestCommonAncestor(4, ...)`
    
    - **判定**：`root == q` (我是 4！)。
        
    - **动作**：**直接返回 `4`**。
        

---

### 第三阶段：结果的上浮与交汇 (Bubbling Up & Meeting) —— 关键时刻！

这是最精彩的部分，请看每个节点是如何处理下属汇报上来的情报的。

**Node 2 的裁决时刻：**

- **左手 (left)**：拿着 `NULL` (7 那边啥也没找到)。
    
- **右手 (right)**：拿着 `4` (4 那边找到了 q)。
    
- **代码逻辑**：
    
    C++
    
    ```
    if (left == NULL && right != NULL) return right;
    ```
    
- **决策**：Node 2 向上级汇报 **4**。
    
    - _潜台词：“报告，我这枝上发现了 q (4)，但没发现 p。”_
        

**Node 5 的裁决时刻 (LCA 诞生处)：**

- **左手 (left)**：拿着 **6** (刚开始从左边找到的)。
    
- **右手 (right)**：拿着 **4** (刚才 Node 2 传上来的)。
    
- **代码逻辑**：
    
    C++
    
    ```
    if (left != NULL && right != NULL) return root;
    ```
    
- **决策**：Node 5 发现左右都有货！它意识到自己就是**分岔口**。
    
- **动作**：**返回 5 (自己)**。
    
    - _潜台词：“报告，p 和 q 分别在我的左膀右臂，所以我就是老大！”_
        

**Node 3 (Root) 的裁决时刻：**

- **左手 (left)**：拿着 **5** (Node 5 传上来的最终结果)。
    
- **右手 (right)**：拿着 `NULL` (Node 1 那边啥也没找到)。
    
- **代码逻辑**：
    
    C++
    
    ```
    if (left != NULL && right == NULL) return left;
    ```
    
- **决策**：Node 3 向上汇报 **5**。
    

**最终结果：5**。

## 701.二叉搜索树中的插入操作
### 第一步：题目本身（了解考查知识点）

**请先停下来，给自己 1-5 分钟思考以下问题：**

> 题目说“可能存在多种有效的插入方式”，但为了简单（且不出错），我们通常选择把新节点放在哪里？
> 
> 1. 是硬塞到树的中间（那样可能需要把原来的节点挪位置）？
>     
> 2. 还是顺着树往下找，直到找到一个 **空位 (Leaf)** 挂上去？
>     
> 
> **提示**：回顾一下刚才做的 **LCA（最近公共祖先）** 或者是 **700. 二叉搜索树中的搜索**。如果你要找这个 `val`，你会走到哪里？如果那个位置是空的，是不是正好放进去？

### 第二步：对答案（逻辑与代码）

#### 1. 核心逻辑

**最简单的策略：永远插在叶子节点（空节点）位置。**

根本不需要重组树的结构（不需要旋转）。你只需要像“搜索”一个值一样去遍历树：

- 如果 `val` 比当前节点大 -> 往右走。
    
- 如果 `val` 比当前节点小 -> 往左走。
    
- **直到走到 `NULL`** -> 说明这里就是它的归宿！在这个位置 `new` 一个新节点，并把它和父节点连起来。
