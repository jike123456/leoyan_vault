## 235.二叉搜索树的公共祖先
### 知识点：二叉搜索树特性：左值小于中值小于右值的特点
二叉搜索树（BST）有什么特殊的性质？这个性质如何帮助我们不用遍历整棵树就能找到目标？

### 对答案：BST 的核心性质是：**左子树所有节点值 < 根节点值 < 右子树所有节点值**。
我们要找 `p` 和 `q` 的最近公共祖先（LCA），只需要从根节点 `root` 开始遍历：

- **情况 A**：如果 `p` 和 `q` 的值都 **大于** 当前节点值 -> 说明它是往 **右** 走的，LCA 肯定在右子树。
    
- **情况 B**：如果 `p` 和 `q` 的值都 **小于** 当前节点值 -> 说明它是往 **左** 走的，LCA 肯定在左子树。
    
- **情况 C**：如果不满足上述两种情况（即一个大一个小，或者其中一个就是当前节点） -> **当前节点就是“分岔点”，也就是最近公共祖先**。
    

**结论**：只要找到第一个让 `p` 和 `q` 分别位于两侧（或其中之一）的节点，就是它了。不需要回溯，不需要像普通二叉树那样用后序遍历。

### 递归法demo
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root->val > p->val && root->val > q->val) {
            return lowestCommonAncestor(root->left, p, q);
        } else if (root->val < p->val && root->val < q->val) {
            return lowestCommonAncestor(root->right, p, q);
        } else return root;
    }
};
```
### 迭代法demo
```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        while(root) {
            if (root->val > p->val && root->val > q->val) {
                root = root->left;
            } else if (root->val < p->val && root->val < q->val) {
                root = root->right;
            } else return root;
        }
        return NULL;
    }
};
```

> **你的笔记**：普通二叉树（LeetCode 236）没有规律，必须后序遍历，从底向上回溯。

- **👨‍🏫 批注（面试高频点）**：
    
    - **路径方向**：这是最本质的区别。
        
        - **BST (235题)**：是**自上而下 (Top-down)** 的。像走迷宫，站在路口（根节点）就知道往左还是往右，**不需要回头**。
            
        - **普通树 (236题)**：是**自下而上 (Bottom-up)** 的。像找人，必须先下到最底下，找到了再一层层汇报上来（回溯）。
            
    - **代码特征**：
        
        - BST 的代码通常没有 `return left + right` 这种汇总逻辑，而是 `return left` **或者** `return right`（单边逻辑）。

### 迭代法
### 第一步：题目本身（逻辑推演）

**思考核心痛点：** 在递归法中，我们到了空节点（`NULL`）直接 `return new Node`，上一层的递归函数会帮我们把这个新节点接住（`root->left = ...`）。 但在迭代法（`while` 循环）中，当你走到 `NULL` 时，你手里只有一个空指针，你已经**丢失了**它的父节点是谁。

> _比喻：你走迷宫走到了死胡同（NULL），想在死胡同口插个旗子，但你发现你连这堵墙是属于哪个路口的都忘了。_

**解决方案：** 我们需要一个**“双指针”**策略。

- `cur`：负责探路，一直走到 `NULL` 为止。
    
- `parent`：负责**记录**，永远跟在 `cur` 后面一步。当 `cur` 掉进空坑里时，`parent` 正好站在悬崖边，这时候就可以通过 `parent` 把新节点拉上来。

第二步：对答案（标准代码）
```cpp
class Solution {
public:
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        if (root == NULL) {
            TreeNode* node = new TreeNode(val);
            return node;
        }
        TreeNode* cur = root;
        TreeNode* parent = root; // 这个很重要，需要记录上一个节点，否则无法赋值新节点
        while (cur != NULL) {
            parent = cur;
            if (cur->val > val) cur = cur->left;
            else cur = cur->right;
        }
        TreeNode* node = new TreeNode(val);
        if (val < parent->val) parent->left = node;// 此时是用parent节点的进行赋值
        else parent->right = node;
        return root;
    }
};
```

**代码细节自我拷问：**

1. **为什么需要 `parent = cur`？**
    
    - 因为 `cur` 最后变成了 `NULL`，你无法对 `NULL` 操作 `NULL->left`。必须操作 `parent->left`。
        
2. **最后的 `if-else` 是干嘛的？**
    
    - 我们虽然找到了 `parent`，但不知道新节点该挂在 `parent` 的左腿还是右腿上，所以需要再比一次大小 (`val < parent->val`)。
