# 12、差速模型的输入输出是什么？怎么计算出来的？

差速模型这里做的是**运动学逆解**：把上层给的底盘目标速度，换算成左右轮各自应该达到的目标速度。

### 1. 输入是什么？

输入是上层控制指令里的两个量：

```c
vx_mmps    // 机器人前进方向线速度，单位 mm/s
wz_mradps  // 机器人绕自身中心旋转的角速度，单位 mrad/s
```

也就是：

```text
输入 = 底盘线速度 vx + 底盘角速度 wz
```

差速底盘没有横向平移能力，所以这里不使用 `vy_mmps`。文档 3.5.3 也说明，差速模型下上层运动指令主要包含 `vx_mmps` 和 `wz_mradps`，然后换算出左右轮目标速度。

### 2. 输出是什么？

输出是左右轮目标线速度：

```c
vL_ref   // 左轮目标速度，单位 mm/s
vR_ref   // 右轮目标速度，单位 mm/s
```

也就是：

```text
输出 = 左轮目标速度 vL_ref + 右轮目标速度 vR_ref
```

这两个速度后面会作为 PID 的目标值，和编码器反馈速度比较，再算 PWM 输出。

### 3. 怎么计算？

核心公式是：

```text
wz_rad = wz_mradps / 1000.0

half_base = WHEEL_BASE_MM / 2

vL_ref = vx_mmps - wz_rad * half_base
vR_ref = vx_mmps + wz_rad * half_base
```

代码形式就是：

```c
float wz_rad = (float)wz_mradps / 1000.0f;
float half_base = WHEEL_BASE_MM * 0.5f;

float vL = (float)vx_mmps - wz_rad * half_base;
float vR = (float)vx_mmps + wz_rad * half_base;

vL = clampf(vL, -MAX_WHEEL_SPEED_MMPS, MAX_WHEEL_SPEED_MMPS);
vR = clampf(vR, -MAX_WHEEL_SPEED_MMPS, MAX_WHEEL_SPEED_MMPS);

*vL_mmps = vL;
*vR_mmps = vR;
```

### 4. 为什么是这个公式？

差速车转弯时，左右轮走的圆弧半径不一样：

```text
左轮速度 = 车体中心速度 - 角速度 × 半轮距
右轮速度 = 车体中心速度 + 角速度 × 半轮距
```

因为机器人绕中心转动时，离旋转外侧更远的轮子速度要更快，内侧轮子速度要更慢。  
所以：

```text
wz > 0 时：左轮速度减小，右轮速度增大
wz = 0 时：左右轮速度相等，直线运动
vx = 0 且 wz != 0 时：左右轮一正一反，原地旋转
```

例如：

```text
vx = 100 mm/s
wz = 1000 mrad/s = 1 rad/s
WHEEL_BASE_MM = 200 mm
half_base = 100 mm
```

则：

```text
vL = 100 - 1 × 100 = 0 mm/s
vR = 100 + 1 × 100 = 200 mm/s
```

说明右轮比左轮快，车体向左/右发生转向，具体方向取决于坐标系定义。

一句话总结：

**差速模型输入是底盘的 `vx_mmps` 和 `wz_mradps`，输出是左右轮目标速度 `vL_ref`、`vR_ref`；计算方法是用线速度加减“角速度 × 半轮距”，得到左右轮各自的目标线速度。**

# 13、PID 输出如何映射到 PWM？

PID 输出映射到 PWM，本质上是把 **PID 算出来的有符号控制量** 转成电机驱动能识别的：

```text
方向信号 DIR + PWM 占空比
```

流程是：

```text
目标轮速 v_ref
  ↓
编码器反馈实际轮速 v_meas
  ↓
误差 error = v_ref - v_meas
  ↓
PID 计算输出 u
  ↓
u 限幅
  ↓
u 的正负决定方向
  ↓
|u| 映射成 PWM 占空比
  ↓
写入定时器 CCR
```

### 1. PID 先算出控制量

对左右轮分别做 PID：

```c
float err = target_speed - actual_speed;

float u = Kp * err
        + Ki * integral
        + Kd * derivative;
```

这里的 `u` 不是速度，而是控制输出量，可以理解成“电机应该加多大力”。

例如：

```text
u > 0：电机正转
u < 0：电机反转
u = 0：停止
```

文档里控制任务收到目标速度后，会进入周期控制流程，读取反馈速度并进行 PID 调速，最后输出到电机驱动。

### 2. 对 PID 输出做限幅

PID 算出来的值不能无限大，必须限制在 PWM 允许范围内：

```c
if (u > PWM_MAX) {
    u = PWM_MAX;
} else if (u < -PWM_MAX) {
    u = -PWM_MAX;
}
```

比如定时器 PWM 最大计数是 `1000`，那么输出范围就是：

```text
-1000 ~ +1000
```

### 3. 正负号决定电机方向

PID 输出 `u` 的正负用于控制方向引脚：

```c
if (u > 0) {
    motor_set_dir(FORWARD);
} else if (u < 0) {
    motor_set_dir(REVERSE);
} else {
    motor_stop();
}
```

也就是：

```text
u > 0  → 正转
u < 0  → 反转
u = 0  → 停止
```

### 4. 绝对值映射成 PWM 占空比

方向确定后，PWM 只使用 `u` 的绝对值：

```c
pwm = fabs(u);
```

如果 PWM 定时器的 ARR 是 `1000`，那么：

```text
pwm = 0      → 0% 占空比
pwm = 500    → 50% 占空比
pwm = 1000   → 100% 占空比
```

写入定时器比较寄存器：

```c
__HAL_TIM_SET_COMPARE(&htim, TIM_CHANNEL_x, pwm);
```

### 5. 如果 PID 输出是百分比，需要再换算

有些代码里 PID 输出不是 `0~ARR`，而是百分比，比如 `0~100`。  
这种情况下要换算成定时器比较值：

```c
uint16_t ccr = (uint16_t)(duty_percent * PWM_ARR / 100.0f);
```

例如：

```text
PID 输出 = 60
PWM_ARR = 1000

CCR = 60 × 1000 / 100 = 600
```

也就是 60% 占空比。

### 6. 实际代码通常会加死区补偿

电机在 PWM 太小时可能转不动，所以如果目标速度不是 0，但 PID 输出很小，可能会加一个最小启动 PWM：

```c
if (target_speed != 0 && pwm > 0 && pwm < PWM_MIN) {
    pwm = PWM_MIN;
}
```

例如：

```text
PWM_MIN = 120
PID 输出绝对值 = 50
实际输出 PWM = 120
```

这样可以克服电机静摩擦。

### 7. 举个例子

假设：

```text
PWM_MAX = 1000
PID 输出 u = -350
```

那么映射结果是：

```text
方向：反转
PWM：350
占空比：35%
```

如果：

```text
PID 输出 u = 1200
```

先限幅：

```text
u = 1000
```

映射结果：

```text
方向：正转
PWM：1000
占空比：100%
```

一句话总结：

**PID 输出先限幅，然后用正负号控制电机方向，用绝对值作为 PWM 占空比写入定时器；左右轮分别执行这一套映射，最终驱动两个电机达到目标速度。**
