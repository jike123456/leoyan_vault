# 7、解析到有效指令后，系统是如何处理的？

解析到有效指令后，系统不会在通信任务里直接控制电机，而是把指令**转换成业务数据、保存最新命令、再通知控制任务处理**。

整体流程是：

```text
CRC 校验通过
  ↓
进入 on_valid_frame()
  ↓
再次检查协议字段是否合法
  ↓
解析 payload
  ↓
生成 CmdVel_t 指令结构体
  ↓
保存为最新速度命令 s_latest
  ↓
通知 ControlTask 有新命令
  ↓
ControlTask 读取最新命令并执行控制逻辑
```

### 1. 先进入 `on_valid_frame()`

当前帧只有在状态机解析完整、CRC 校验通过后，才会进入：

```c
on_valid_frame();
```

但进入这个函数后，还不是马上执行控制，而是继续检查协议字段，比如版本号、消息类型、标志位、序列号、长度等。文档 3.4.5.1 里说明，有效帧处理的触发条件比较严格：完整接收一帧、CRC 通过、关键字段符合系统预期，才认为当前帧是有效帧。

典型代码逻辑是：

```c
static void on_valid_frame(void)
{
    if (s_ver    != PROTO_VER_EXPECT) return;
    if (s_msg_id != MSG_ID_CMD_VEL)   return;
    if (s_flags  != FLAGS_EXPECT)     return;
    if (s_seq    != SEQ_EXPECT)       return;
    if (s_len    != CMD_VEL_LEN)      return;

    ...
}
```

### 2. 解析 `payload`，生成速度指令

如果字段都合法，系统才会真正解析 payload。

对于 `CMD_VEL` 指令，payload 里包含 3 个 `int16_t` 类型的数据：

```text
vx_mmps   // x 轴速度，单位 mm/s
vy_mmps   // y 轴速度，单位 mm/s
wz_mradps // 角速度，单位 mrad/s
```

代码按小端格式解析：

```c
CmdVel_t v;

v.vx_mmps   = le_i16(&s_payload[0]);
v.vy_mmps   = le_i16(&s_payload[2]);
v.wz_mradps = le_i16(&s_payload[4]);
v.rx_tick   = xTaskGetTickCount();
v.valid     = true;
```

也就是说，通信层收到的原始字节会被转换成业务层可以直接使用的结构体 `CmdVel_t`。文档 3.4.5.2 中说明，这一步的本质是把“通信层的数据表示”转换成“业务层可以直接使用的参数”。

### 3. 保存为最新命令

解析完成后，系统会把这条指令保存到一个静态全局变量里，例如：

```c
static CmdVel_t s_latest = {0};
```

保存时要注意线程安全，因为通信任务和控制任务可能同时访问这块数据。文档中使用临界区保护：

```c
taskENTER_CRITICAL();
s_latest = v;
taskEXIT_CRITICAL();
```

这样可以避免 ControlTask 读取时，CommTask 正好写到一半，导致读到不完整或不一致的数据。文档 3.4.5.4 后面也强调，读取最新 `CmdVel_t` 时通过函数接口访问，并用临界区保护结构体拷贝。

### 4. 通知控制任务

保存完最新命令后，通信任务会通知控制任务：

```c
if (g_controlTaskHandle) {
    xTaskNotify(g_controlTaskHandle, NOTIF_NEW_CMD, eSetBits);
}
```

这里的意思是：**通信任务只负责接收、解析、校验和保存指令，不直接驱动电机；真正的控制逻辑交给 ControlTask。**

文档 3.4 的总体流程也说明，有效处理阶段会根据消息 ID 解析有效载荷，更新全局最新命令，并通过 FreeRTOS 任务通知机制通知 ControlTask 有新命令到来。

### 5. ControlTask 再读取并执行

ControlTask 收到通知后，会通过接口函数读取最新命令，例如：

```c
CmdVel_t Comm_GetLatestCmdVel(void)
{
    CmdVel_t out;

    taskENTER_CRITICAL();
    out = s_latest;
    taskEXIT_CRITICAL();

    return out;
}
```

然后 ControlTask 根据 `vx_mmps、vy_mmps、wz_mradps` 执行后续控制，比如运动学解算、速度目标更新、电机控制等。

所以可以总结为一句话：

**解析到有效指令后，CommTask 只把原始 payload 转成 `CmdVel_t`，保存为最新命令，并通知 ControlTask；ControlTask 再安全读取该命令并执行真正的运动控制。**
