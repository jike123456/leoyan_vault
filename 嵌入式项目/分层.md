## 第 1 层：硬件层

就是芯片和外设本身：

GPIO
USART
TIM
EXTI
NVIC
寄存器

这一层你平时不直接“看见”，但它是真正执行的地方。

## 第 2 层：HAL/CMSIS 层

这是官方提供的底层库：

HAL_GPIO_WritePin()
HAL_UART_Transmit()
HAL_UART_Receive_IT()
HAL_TIM_Base_Start_IT()

这一层做的事是：

把复杂寄存器操作，包装成你能直接调用的函数。

## 第 3 层：BSP 层

就是你说的这些：

bsp_led.*
bsp_key.*
bsp_uart.*

这一层做的事是：

针对“你这块板子”的硬件，再做一层更简单的封装。

比如：

HAL 知道怎么写 GPIO
BSP 知道“这块板子的 LED 在哪根引脚上”

所以你上层不用记 GPIOF PIN9，只要写：

BSP_LED_On();
## 第 4 层：App 层

比如：

app_shell.*

这一层做的事是：

不直接碰硬件，而是做功能逻辑。

比如：

收到字符串 "led on"
解析成命令
决定调用 BSP_LED_On()

它关心的是“业务”，不是“引脚”。

## 第 5 层：main.c

main.c 最好只做两件事：

初始化
主循环调度

比如：

```c
int main(void)
{
    HAL_Init();
    SystemClock_Config();

    MX_GPIO_Init();
    MX_USART1_UART_Init();

    BSP_LED_Init();
    BSP_UART_Init();
    APP_Shell_Init();

    while (1)
    {
        APP_Shell_Task();
    }
}
```

你看，main.c 不干细节，只负责“把所有模块组织起来”。
